=========================
查看命令行帮助
=========================

Viewing command-line help

.. tab:: 中文

   要查看受支持的 conda 命令列表，请在终端窗口中运行:

   .. code-block:: bash

      conda --help

   或

   .. code-block:: bash

      conda -h

   要获取特定命令的帮助，请键入命令名称，后跟“--help”。

   **示例**

   要查看“create”命令的帮助，请在终端窗口中运行:

   .. code-block:: bash

      conda create -h

   .. note::
      您可以在 :doc:`commands <../../commands/index>` 中看到相同的命令帮助。

.. tab:: 英文

   To see a list of supported conda commands, in your terminal window, run:

   .. code-block:: bash

      conda --help

   or

   .. code-block:: bash

      conda -h

   To get help for a specific command, type the command name
   followed by ``--help``.

   **Example**

   To see help for the ``create`` command, in your terminal window, run:

   .. code-block:: bash

      conda create -h

   .. note::
      You can see the same command help in :doc:`commands <../../commands/index>`.
